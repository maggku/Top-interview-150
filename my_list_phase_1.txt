Here are the Sliding Window problems, sequenced from basic to advanced:

Fixed-size window — the simplest form

Maximum Average Subarray I (643) — fixed window sum, the cleanest intro
Find All Anagrams in a String (438) — you saw this in Strings; fixed window + frequency map

Variable-size window — expand and shrink

4. Fruit Into Baskets (904) — variable window with a "at most K distinct" constraint, same skeleton as #3
5. Max Consecutive Ones III (1004) — variable window with a "budget" (flips allowed) instead of distinct count

Shrink-from-left pattern (condition-based)
6. Minimum Size Subarray Sum (209) — shrink window once sum condition is met, classic template
7. Longest Repeating Character Replacement (424) — variable window + frequency map + a replacement budget
8. Minimum Window Substring (76) — repeat from Strings; the hardest "shrink from left" problem, combines everything above

Counting subarrays (not just longest/shortest)
9. Subarray Product Less Than K (713) — counting valid windows, not just finding one
10. Number of Substrings Containing All Three Characters (1358) — counting + frequency map combo

Two-pointer/window hybrids
11. Permutation in String (567) — fixed window + frequency map, sibling problem to #2
12. Longest Substring with At Most Two Distinct Characters (159) — same shape as Fruit Into Baskets, good repetition
13. Longest Substring with At Most K Distinct Characters (340) — generalizes #12, premium/locked on some plans but worth knowing

Prefix sum + window (bridges into other topics)
14. Subarray Sum Equals K (560) — technically prefix sum + hashmap, not pure sliding window, but commonly grouped here since it looks like a window problem — good for pattern-recognition training
15. Continuous Subarray Sum (523) — same prefix sum + hashmap idea, adds a modulo condition

Harder / capstone
16. Sliding Window Maximum (239) — monotonic deque, a real step up in difficulty, important for the Stack section later too
17. Sliding Window Median (480) — heap-based, hard, optional but good if you want the full picture
18. Frequency of the Most Frequent Element (1838) — sort + variable window + budget, nice combo problem
19. Count Number of Nice Subarrays (1248) — variable window with a parity/count condition, good final practice
20. Minimum Number of K Consecutive Bit Flips (995) — window + greedy simulation, a solid capstone that ties window thinking to greedy logic

A couple of things worth flagging for later, since you're just saving this for now:

#14 and #15 aren't strictly sliding window — they sneak in prefix-sum + hashmap thinking, which is a great "gotcha" to notice, since window problems and prefix-sum problems often look identical at first glance but need different tools.
#16 (Sliding Window Maximum) is the one most people get stuck on. It needs a monotonic deque, which is a new data structure pattern — don't worry if it takes a few tries.
